# ✏️ Anleitung: So pflegst du die Mathe-Seite

**Die Seite:** https://lueb-sammlung.github.io/Unterrichtsmaterialien/

**Du bist hier richtig**, wenn du etwas auf der Seite ändern willst. Diese Anleitung steht immer hier. Du findest sie über den Link **✏️ Seite bearbeiten** ganz unten auf der Seite.

> **Vorher:** Oben rechts muss dein Profilbild zu sehen sein. Steht dort **Sign in**, klick darauf und melde dich an.

---

## So funktioniert die Seite

| Hier bei GitHub …               | … wird auf der Seite zu         |
|---------------------------------|---------------------------------|
| ein Ordner, z. B. `Mathematik 5` | ein Kasten mit Überschrift      |
| ein Ordner im Ordner, z. B. `Bruchrechnung` | eine blaue Zwischenüberschrift im Kasten |
| eine Datei, z. B. `Brüche kürzen.pdf` | ein Eintrag „Brüche kürzen“ mit **Ansehen** |
| eine Zeile in `links.txt`       | ein Internet-Link mit **Öffnen** |

**Nach jeder Änderung 2 Minuten warten**, dann die Seite neu laden. Erst dann ist die Änderung zu sehen.

**Keine Angst:** GitHub merkt sich jede Änderung, und alles lässt sich wieder rückgängig machen.

---

## 📄 Ein Arbeitsblatt hinzufügen

1. **Datei vorher passend benennen.** Der Dateiname wird zum Titel auf der Seite. Also zum Beispiel `Brüche kürzen.pdf` statt `Scan_0034.pdf`.
2. Auf die passende Gruppe klicken:
   - 👉 [**Mathematik 5** – Datei hochladen](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/upload/main/Mathematik%205)
   - 👉 [**Mathematik 6** – Datei hochladen](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/upload/main/Mathematik%206)
   - 👉 [**Mathematik Kurs** – Datei hochladen](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/upload/main/Mathematik%20Kurs)
3. Die Datei in das große Feld ziehen. Oder auf **choose your files** klicken und die Datei auswählen.
4. Warten, bis die Datei unten in der Liste steht.
5. Ganz unten auf den grünen Knopf **Commit changes** klicken. Das heißt so viel wie „Speichern“.

✅ Fertig. Nach 2 Minuten steht das Arbeitsblatt auf der Seite.

**Mehrere Dateien auf einmal** gehen auch. Einfach alle zusammen in das Feld ziehen.

---

## 🔗 Einen Internet-Link hinzufügen

1. Auf die passende Gruppe klicken:
   - 👉 [**Mathematik 5** – Links bearbeiten](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/edit/main/Mathematik%205/links.txt)
   - 👉 [**Mathematik 6** – Links bearbeiten](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/edit/main/Mathematik%206/links.txt)
   - 👉 [**Mathematik Kurs** – Links bearbeiten](https://github.com/lueb-sammlung/Unterrichtsmaterialien-Neu/edit/main/Mathematik%20Kurs/links.txt)
2. Ans Ende des Textes klicken und mit der **Enter-Taste** eine neue Zeile anfangen.
3. Erst den Titel schreiben, dann einen senkrechten Strich `|`, dann die Internetadresse:
   ```
   Bruchrechnen üben | https://www.beispiel.de
   ```
   Den Strich `|` bekommst du so:
   - **Windows:** `AltGr` gedrückt halten und die Taste `<` drücken (links unten neben dem `Y`).
   - **Mac:** `Alt` + `7`
   Die Internetadresse am besten im Browser oben aus der Adresszeile kopieren.
4. Oben rechts auf **Commit changes…** klicken, im kleinen Fenster nochmal auf **Commit changes**.

Zum **Entfernen eines Links** die ganze Zeile löschen und genauso speichern.

---

## 🗑️ Ein Arbeitsblatt löschen

1. Auf den Ordner klicken, z. B. **Mathematik 6**.
2. Auf die Datei klicken.
3. Oben rechts auf die **drei Punkte `…`** klicken → **Delete file**.
4. Auf **Commit changes…** klicken, im kleinen Fenster nochmal auf **Commit changes**.

---

## 🔄 Ein Arbeitsblatt austauschen oder umbenennen

- **Neue Version:** Die Datei mit **genau dem gleichen Namen** hochladen wie oben bei „Ein Arbeitsblatt hinzufügen“. Die alte Version wird dann ersetzt.
- **Anderer Titel:** Die alte Datei löschen und unter dem neuen Namen neu hochladen.

---

## 📂 Ein Thema anlegen (blaue Zwischenüberschrift)

1. **Auf dem eigenen Computer** einen Ordner anlegen, z. B. `Bruchrechnung`, und die Arbeitsblätter hineinlegen.
2. Bei der passenden Gruppe auf „Datei hochladen“ klicken (Links siehe oben).
3. **Den ganzen Ordner** in das große Feld ziehen, nicht die einzelnen Dateien.
4. **Commit changes** klicken.

Das klappt in **Chrome, Edge oder Firefox**, aber nicht immer in Safari.

**Reihenfolge der Themen:** Eine Zahl vor den Namen setzen, also `1 Natürliche Zahlen`, `2 Geometrie`. Die Zahl wird auf der Seite nicht angezeigt.

---

## ❓ Wenn etwas nicht klappt

**Die Änderung ist nicht zu sehen**
- 2 Minuten gewartet? Die Seite neu laden: **Windows:** `Strg` + `F5`, **Mac:** `Cmd` + `Shift` + `R`.
- Oben auf den Reiter **Actions** klicken:
  - 🟡 Gelber Punkt: Die Seite wird noch gebaut. Kurz warten.
  - ✅ Grüner Haken: Alles in Ordnung. Nochmal neu laden.
  - ❌ Rotes Kreuz: Bitte Bescheid sagen.

**Es gibt kein „Commit changes“ oder kein „Add file“:** Du bist nicht angemeldet. Oben rechts auf **Sign in** klicken.

**Etwas ist schiefgegangen:** Nichts weiter anfassen und Bescheid sagen. Es lässt sich alles wiederherstellen.

---

## ⚠️ Bitte beachten

- **Die Seite ist für alle im Internet sichtbar.** Keine Namen von Schülern, keine Noten, keine Fotos von Schülern hochladen.
- **Lösungen** erst hochladen, wenn die Klasse sie sehen darf.
- **Keine Seiten aus Schulbüchern** einscannen und hochladen, nur eigene Arbeitsblätter.
- **Diese Dateien bitte nicht verändern oder löschen:** `seite_erstellen.py`, den Ordner `.github` und `README.md` (diese Anleitung). Sie sorgen dafür, dass die Seite funktioniert.
